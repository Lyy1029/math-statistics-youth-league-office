# 数学与统计学院团委办公室

这是一个面向高校学院团委办公室的 Codex Skill，用于将团委日常工作转换为可执行、可审核、可归档的规范流程和办公成果。

## 主要能力

- 将学校或书记通知改写为学生可直接执行的群通知，并整理报名字段、附件和建群建议。
- 统筹一般活动、大型活动、会务、教室借用、社会实践和材料报送。
- 支持评奖评优、招新留任、学生信息台账、版本管理和隐私归档。
- 从已批准名单生成 DOCX 和 PDF 活动证明或突出贡献证明，自动检查重复、空项、批准状态、上下文错配和均分列宽。

## 证明生成特点

- 普通证明与突出贡献证明分别使用独立模板。
- 名单使用无框线、固定布局、均分列宽的居中表格。
- 突出贡献证明的正文与名单之间固定留一个完整空白行，长活动名换行时名单会同步下移。
- 常规制证采用“一次自动预检并生成 + 一次人工终检”，不在每个审批层级重复格式检查。

## 工作原则

- 以本次正式通知、当前学年方案和负责人指示为准，不从历史文件推断当年资格或分值。
- 保留真实审批链和人工决策节点，不冒充已审核、已盖章或已发布。
- 实行数据最小化，不把电话、身份证号、内部评分等字段写入对外证明。
- 明确排除通讯信息、视频、表情包和托特包素材，也不生成、复制或合成公章。

## 仓库结构

- `youth-league-office/SKILL.md`：技能入口与核心路由。
- `youth-league-office/references/`：通知、活动、证明、评奖、台账、归档等分流规则。
- `youth-league-office/scripts/`：证明和表格模板生成器及回归测试。
- `youth-league-office/assets/`：经清理的 DOCX/XLSX 模板。

## 使用

将 `youth-league-office/` 目录放入 Codex 可读取的 skills 位置，然后在任务中调用 `$youth-league-office`。正式使用前请以当前学年制度和现行审批链进行校准。
