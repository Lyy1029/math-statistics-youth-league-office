# 评奖评优、招新留任与社会实践

## 评奖评优

标准流程：

`读取最新上级通知 → 提炼资格/名额/材料/截止 → 发布经审核通知 → 统一收件并登记 → 完整性与真实性核验 → 退补 → 复核 → 按指定结构报送 → 跟进审批/公示 → 结果通知与归档`

收件台账至少记录内部人员键、班级、提交时间、材料份数、缺项、退补状态和最终状态。姓名、荣誉、职务、成绩、排名、证书页、文件名和扫描清晰度须逐项核对。

技能只能把正式规则转成核验清单，不能自行设定名额、放宽资格、决定候选人或替代最终审核。涉及成绩、排名、身份证明、政治面貌等数据时遵循最小化和分级授权；公示前按正式制度脱敏。

## 招新、面试与留任

标准流程：

`确认名额与岗位 → 发布表单 → 去重/完整性检查 → 回避登记 → 按已批准评分量表面试 → 独立评分与复核 → 录取/调剂决定 → 通知 → 交接培训 → 受限归档`

若没有统一评分维度、权重、回避机制、录取线或调剂规则，只能整理材料和暴露缺口，不能从历史表单反推制度。申请表中的照片、学号、联系方式、绩点、身份证号、自述等不得进入技能示例；默认仅报告字段、数量、缺失和重复情况。

留任申请、汇总表与压缩包可能是重复副本。先确认唯一权威目录和冻结版本，不以文件份数推断申请人数。

## 社会实践

报名类实践的推荐闭环：

`报名验证 → 建群/通知 → 物料需求汇总 → 领用签收 → 实施 → 照片/报告/心得/登记表收集 → 学院审核/盖章 → 成果清单与归档`

成果追踪表应为每列命名并定义完成标准；无标题列、真假值含义不明、负责人联系方式缺失或团队状态冲突时，先请求解释。物料按申请、实发、签收、退回四个数量分开记录。

## 共同审核规则

- 最新正式文件优先于往年样例和目录命名。
- 建立接收件数、合格件数、退补件数和最终报送件数的勾稽关系。
- 不在聊天或普通日志中复述真实个人值。
- 需要报学校的文件逐级审核，并由团委书记审核后发送。
- 每次报送保留时间、渠道、文件版本、接收方和结果；压缩包仅作交付，不作为唯一档案。
