# 通知、一般活动、大型活动与会务

## 通用原则

每项活动都建立任务卡、唯一正式名称、倒排期、负责人、审核链和归档目录。时间节点是默认基线；上级通知另有要求时，以最新正式通知为准并记录变更。

## 通知

通知的文字改写、报名字段、附件缺失处理和建群判断以 [学生通知改写与发布准备](notice-writing.md) 为准。本文件只补充活动执行衔接：纪念活动还需简述背景、保持庄重、将集合时间提前 10–15 分钟并写明纪律；提供学院活动证明时，必须说明以经核验的实际签到/签退或本次批准的等效参与记录为准。

下派链通常为 `团委书记 → 团委副书记 → 部长/副部长 → 承办人`；成果审核回报链沿原路反向逐级提交。执行人完成事实核对和文字校对后再报审，不得把草稿直接发布；发布人、渠道和发布时间必须明确。

## 教室借用

当前普通教室代借主要由其他部门、班级或活动负责人向办公室提出需求，办公室核验后由办公室主任使用学校借教室账号办理。账号、密码和验证码不得记录在任务卡、技能或聊天中，也不得交给申请人。

当前本地办理基线为独立《数统学院借教室步骤》和《团委办公室工作制度与工作法手册》。普通教室流程为：

`申请人报部门/班级、时间、内容、地点 → 办公室核验 → 办公室主任线上代借并发结果截图 → 活动负责人核对 → 数统楼306取纸质申请 → 辅导员签字、学院盖章 → 师生服务大厅A109审核盖章并取三联 → 网络中心、物业各收一联，承办方自留一联 → 活动前确认开门与设备`

至少记录申请单位、活动内容、日期、完整时段、期望区域/地点、预计人数、设备需求、申请人受控联系方式和核对人。手册建议至少提前三天申请；教室按整段借用，当前段号为 `0102 / 030405 / 0607 / 080910 / 111213`。具体位置、系统界面、段号和三联规则出现新通知、系统变化或现场反馈时重新核对，不能把当前基线当作永久制度。

报告厅采用线下借用，不进入上述普通教室线上代借流程。本技能只提示申请人转入当前线下流程；未取得单独指南与授权时，不代拟办理步骤，也不声称已经借到。

不得从 `通讯信息/**` 获取联系人，也不得把旧文档中的个人微信或手机号写入技能。需要联系时请用户单独提供当前授权的岗位联系人，优先使用岗位称谓。

## 大型活动默认倒排期

- T-2至3周：确定主题、时间、地点、规模、流程和批准人；建立总协调、文案、技术、场务、后勤、礼仪、签到等岗位；形成方案和风险清单。
- 议程定稿后制作 PPT；T-1天拷贝到现场电脑并测试字体、比例、链接和 PDF 备份。
- 活动日 T-5h：全员到位、点名、布场；T-4h：全流程彩排；T-30min：停止彩排、入场引导和签到；活动后：退场、清场、物资回收和复盘。

本技能不制作、读取、枚举或审核视频，也不处理视频压缩包、嵌入关系、文件名或元数据。活动中的视频事项整体转交其他流程；本技能不记录其文件级收件或交接状态。

## 会务输出

大型活动通常需要：活动方案、岗位与备岗表、议程、PPT/PDF、座区图、座签索引、物资清单、签到/签退表、安全预案、场地验收表、异常记录和复盘。获奖主表、表彰决定、上台代表、座位/座签必须使用同一冻结版名单并记录版本。

## 安全边界

不得照抄旧安全预案。正式预案至少由有权负责人确认场地、人数、总指挥及替补、报警和医疗联系机制、出口/集合点、消防与电气检查、设备故障、停电、天气、拥挤踩踏、突发疾病、无障碍需求、演练和事件记录。发生危险时优先报警、疏散并服从校保卫、消防和医疗人员；不得指示未经训练的学生冒险灭火或控制当事人。
